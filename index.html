Organizá tus elementos fácilmente

Flexbox es una herramienta de CSS que permite ordenar, alinear y distribuir elementos dentro de un contenedor. Se adapta al espacio disponible y facilita la creación de páginas que funcionan en computadoras y celulares.

01 / CONCEPTOS

¿Qué podemos hacer con Flexbox?

Estas son algunas propiedades importantes.

01

Dirección

flex-direction define si los elementos se ordenan en fila o en columna.

02

Alineación

justify-content y align-items permiten alinear los elementos.

03

Adaptación

flex-wrap permite que los elementos bajen a otra línea cuando es necesario.
